# BatzProjectt

Protótipo de interface desktop em Java Swing para uma aplicação de gestão de loja. A tela inicial lista áreas para produtos e estoque, Shopee, financeiro e relatórios.

O projeto Maven fica em `OneDrive/Documentos/NetBeansProjects/BatzProjectt/` e inclui formulários `.form` do NetBeans. Algumas telas ainda estão em estrutura inicial.
